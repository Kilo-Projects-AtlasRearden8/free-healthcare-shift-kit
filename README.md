# Free Healthcare Shift Kit

Fillable, printable, no-account-needed worksheets for healthcare workers: brain sheets, shift handover templates, continuing education (CE) trackers, and medication logs.

**Education only.** These tools are organization and learning aids. They are not medical advice, not a substitute for clinical judgment, and not a substitute for your facility's policies. Always follow your employer's protocols and your state's scope-of-practice rules.

## Contents

| File | What it is |
|------|------------|
| `brain-sheet.html` / `brain-sheet.md` | Shift brain sheet: patient snapshot, SBAR-style assessment, vitals, lines/tubes, meds, to-dos |
| `handover-template.html` / `handover-template.md` | Shift handover template: offgoing/oncoming nurses, SBAR handoff, pending tasks, signatures |
| `ce-tracker.html` / `ce-tracker.md` | Continuing education tracker: courses, hours, cost, license renewal deadline |
| `medication-log.html` / `medication-log.md` | Medication log: time, medication, dose, route, given by, initials |

## How to use

1. Open any `.html` file in your browser (Chrome, Edge, Safari, Firefox). No account, no sign-up, no internet needed after you have the files.
2. Fill in the fields directly in the browser.
3. Press `Ctrl+P` / `Cmd+P` to print. Print styles hide on-screen controls and produce a clean worksheet.
4. Markdown (`.md`) versions are included if you prefer to edit, print from a markdown viewer, or copy into your own notes.
